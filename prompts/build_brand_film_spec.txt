输出 markdown，标题必须是：
# Brand Film Spec - {product_name}

必须包含以下章节，章节名保持一致：

## 结论
- 推荐路线
- 商业类型 / 制作方式
- 表达形式
- 一句话品牌创意
- 观众记忆点
- 是否值得生成及依据

## 产品事实锁
- 图像来源与角色
- 必须保持的颜色、结构、包装、数量、材质外观和细节
- 跨镜连续性
- 不得新增的产品事实
- 未知且不能进入文案的内容

## 背景与判断
- 品牌 / 产品（未知品牌必须写“未提供”，不能自创）
- 一级类目 / 子类 / subcategory_status
- 假设人群
- 消费者 tension
- 品牌阶段
- 传播目标
- 品类张力
- 品牌资产
- 产品真相

## 类目证据链
- 当前 profile id
- 每个 critical proof group 如何由具体镜头证明
- proof tag 与镜头 id 对应
- 哪些内容是 observed，哪些只是 creative device
- claim 边界

## 电影化路线
- 电影类型
- 风格关键词（不得引用真实导演、受版权保护广告片或参考样本品牌）
- 打光逻辑
- 视觉想法
- 品牌世界
- 主体 / 主角
- 产品叙事功能
- 运动脊柱
- 最终品牌句；用户未提供品牌句时写“待品牌提供”，不要代造

## 15秒节奏
按 brief.duration_seconds 拆成 4-6 个时间段。每段必须写清：时间、画面、镜头/运动、声音、proof tags、产品可见度、产品保真控制、文案或留空理由。

## 制作控制
- 镜头数量与转场
- 剪辑节奏
- 光线与色彩
- 声音 / BGM
- 人物、手部、食物物理或穿着关系
- 产品 / 包装 / 完整轮廓
- 文字、logo 与品牌资产
- 横竖屏判断

## 原创性与风险
- 独特开场
- 品牌视觉代码
- 产品后果或消费者回报
- 一眼记忆
- 品类 claim 风险
- 产品漂移与连续性风险
- 与参考样本的去相似化说明

## 视频生成 Adapter 约束
- required inputs
- optional keyframes
- adapter 必须保留
- adapter 禁止改写
- 首轮失败只改一个变量的 fallback
- retry budget
- 直接换候选的触发条件
- 返回 Codex 的 telemetry

硬性要求：
1. 这是给下游视频 agent 的创意导演规格书，不是普通 text-to-video prompt。
2. 必须整合 score、hard_gate_results、render_decision 和 storyboard_review；不能只复述候选。
3. 产品必须在 {must_show_second} 秒前出现，并在整片保持 product_fidelity_lock。
4. 类目证据链必须覆盖全部 critical proof groups；缺失时不能假装通过，应在结论写 should_render=false。
5. 严格遵守 person_policy、truth_boundaries 和 claim_boundaries。
6. 不得生成品牌历史、品牌名、slogan、认证、成分、营养、医疗功效、材质纯度、天然宝石、真伪、销量或数字事实，除非输入明确提供。
7. 参考视频只用于结构校准，不能复制人物、包装、产品设计、文案、品牌或特定画面。
8. 输出只包含 markdown 正文，不要代码块，不要额外解释。
