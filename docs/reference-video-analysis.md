# 小云雀三类参考视频拆解

## 范围与方法

本次基准集来自 `data/src` 的 11 条视频：美妆个护 4 条、食品饮料 4 条、服饰配件 3 条。每条视频按时长等分为 8 段，在每段中点抽取一帧，只分析画面和可见字幕，不包含完整音频转写，也不是逐帧剪辑表。

因此，这份分析用于校准“短片怎样证明商品”，不用于复刻人物、品牌、包装、文案或生成画风。机器可读证据见 `harness/reference_video_manifest.json`。

## 共同骨架

11 条视频反复出现同一条 15 秒证据链：

1. `0-2s`：用人物、问题、欲望或使用场景建立立即可懂的钩子，商品已经可辨认。
2. `2-5s`：建立产品身份，同时给出第一个品类证据。
3. `5-9s`：展示最强证据，不重复同一种静物美图。
4. `9-12s`：把证据转换成使用结果、情绪回报或场合价值。
5. `12-15s`：用稳定的商品、包装或完整造型完成锁定。

共同骨架不等于共同模板。三类视频最核心的差异是“什么画面算证据”。

## 三类证据差异

### 美妆个护

必须证明使用部位、产品形态或工具、质地/妆效与可见结果。人物脸部、唇部、眼部、指甲和手部不是装饰，而是商品效果的尺度。最大的风险是把创意演绎写成医疗、永久、无痛、安全或保证见效的事实。

### 食品饮料

必须把包装身份、原料/准备、感官运动和食用/饮用场景串起来。拉丝、蒸汽、液体、回弹和入口可以制造食欲，但不能凭空增加包装里没有的配料、份量、产地、营养或健康功效。

### 服饰配件

必须展示上身、佩戴、上脚或携带关系，再用材质/工艺细节、完整轮廓、动态和场合完成证明。静物微距只能做一段，不能替代人体尺度和完整外形。饰品与鞋包分别需要佩戴尺度、五金/工艺、容量或功能等子类覆盖。

## 对 Harness 的直接结论

- 图片理解必须区分 `observed`、`inferred`、`unknown`，不能让 dense caption 把推断写成事实。
- 候选必须显式提交 `proof_tags`、`product_first_seen_at` 和 `claims_used`，让规则层可检查。
- 评分必须加入 `product_truth_fidelity` 与 `category_proof_coverage`，并按品类 profile 加权。
- shortlist 和 render decision 必须先过品类证据硬门，再比较 overall。
- `brand-film-spec` 必须包含产品事实锁、品类证据链、claim 边界和视频 renderer fallback。
- 子类使用 `subcategory_status` 与 `subcategory_extension` 扩展，不强迫不准确的归类。
